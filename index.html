本版导入范围
正交盒、atom_style molecular，最多 10,000 个粒子。支持 Masses / Atoms / Bonds、完整 Velocities 和可选的 image flags。含电荷、力场系数、角、二面角或倾斜盒的文件会明确拒绝，避免丢失信息。文件只在浏览器内处理；可用顶部的工程保存与恢复继续编辑。
导入文件的单位由原 in 文件决定。未写 Atoms 样式注释时，本工具按你选择的 molecular 格式解释，不自动识别单位。预览显示文件原始坐标与端点连线，不会自动展开跨周期边界的链。

导出之后，怎样使用？
  1. 先用“读取与受力检查”，查看 LAMMPS 是否报错及初始能量是否合理。
  2. 将 ZIP 解压，终端进入文件夹，运行 lmp -in in.lammps。程序名称以实际安装为准。
  3. 改为平衡模式，观察温度、密度和能量的稳定性。步数到达不等于已经平衡。
  4. 稳定后再学习 RNEMD；用同一稳态时间窗的剖面和交换能量做分析。
在超算上，还需学校提供的 LAMMPS 环境与 Slurm/PBS 等提交脚本。in 文件不包含排队、核数和内存设置。
本版支持正交盒、最多两类粒子与一类键、LJ 约化单位。不能直接生成论文中的 PE/PP 真实材料力场；不含电荷、角、二面角或约束。

日志与解析提示




支持什么日志？怎样理解结果？
支持包含 Step 的单行 thermo 表与多段 run / minimize。可显示 Temp、Press、Density、PotEng、TotEng 等实际输出列。YAML / multi、轨迹和温度分层文件不在本模块的解析范围内。
有 ERROR 的日志仍可用于定位故障；NaN / Inf 不会替换为零。若某段没有 Loop time，本页仅提示缺少结束标记，不能据此判断计算是否仍在运行。单位与能量归一化无法从日志确认时显示“未知”，请核对实际 in 文件。
教学日志来自 128 粒子 WCA/FENE 珠簧链的实际短运行，含读取检查、最小化、NVT、NPT、NVE 和两段 RNEMD。它用于练习读图，不是已验证收敛的材料研究结果。
分析记录 JSON 包含原始日志和当前曲线设置，重新导入时重新计算；CSV 包含当前区间的各列数值，SVG 可用于插图。它们与顶部的结构工程文件分别保存。

一次提交与续算，分别需要哪些文件？
首次运行：完整 ZIP 包含 submit.sh、配套 in.lammps、当前 model.data、参数记录、作业设置和说明。检查点设置只添加到这份作业包，不改动第 02 页的原脚本。
运行中断：从结果目录取出最近一个完整的 checkpoint-nvt / npt / nve 文件，新建目录，在本页选择“从已有 restart 继续运行”，填写来源和文件名。将原二进制文件与生成的 resume.in、submit.sh 放在一起，再提交。ZIP 不会凭空生成 restart。
来源要对应：中断阶段使用原积分器及相同恒定目标温压；checkpoint-阶段.end.restart 在积分器仍启用时保存。原 equilibrated.restart 在 unfix 后保存，可作为新阶段起点。本版不支持升降温程序、任意材料力场或中断 RNEMD 连续采样恢复。
结果单独存放：每次执行新建 run-作业名-作业ID-随机后缀目录，保留此前结果。墙钟到期不保证最后一次检查点已写完整；需要先短续算验证可读性。二进制 restart 尽量用原 LAMMPS 版本与平台读取。
